Atendentes

Clique em uma atendente para ver os detalhes e a lista dela.

    Pontual Consig

    Sites e programas

    Cada atendente tem a sua própria lista. Sites são liberados por um administrador; programas precisam de dois.

    Domínios observados

    Endereços fora da lista que as atendentes acessaram com o modo de observação ligado. Permita os que fazem parte do trabalho.

    Sites nos navegadores

    As atendentes usam navegadores (Google Chrome, Microsoft Edge, Opera ou Mozilla Firefox) com vários perfis, um WhatsApp em cada. Quando uma delas abre um site que não é operacional, o Terminal avisa aqui, com o nome dela e o navegador, sem mostrar nada para ela. Você decide se o site fica liberado ou bloqueado só para ela ou para todas as atendentes; a decisão vale também para os subdomínios. A decisão de uma atendente vale mais que a decisão para todas: o YouTube pode estar bloqueado para todas e liberado só para uma.

    Esperando decisão

    Quais sites podem e quais não podem

    Cada site aparece uma vez: a regra de todas e, ao lado, quem é exceção. Para mudar, escolha para quem e clique em Liberar ou Bloquear. A mudança chega aos navegadores das atendentes em até meio minuto.

    Aplicativos do computador

    As atendentes podem abrir, pela lista "Aplicativos" do Terminal, os aplicativos do Windows, os instalados e os baixados. Na primeira vez que uma delas abre um aplicativo que não é programa cadastrado, ele abre e o pedido chega aqui, com o nome dela. Você decide se o aplicativo fica liberado (abre sem pedir) ou bloqueado (o Terminal não abre mais e fecha o que estiver aberto), só para ela ou para todas as atendentes. A decisão é pelo nome do arquivo (spotify.exe) e a de uma atendente vale mais que a decisão para todas.

    Esperando decisão

    Já decididos

    Mude a decisão quando quiser. O bloqueio chega aos Terminais em até meio minuto.
